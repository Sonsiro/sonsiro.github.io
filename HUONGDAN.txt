CÁCH ĐƯA LÊN WEB
----------------
1. Vào repo: https://github.com/Sonsiro/sonsiro.github.io
2. Mở file index.html → bấm Edit (biểu tượng bút chì).
3. Copy TOÀN BỘ nội dung file index.html trong zip này
   dán đè lên nội dung cũ → Commit changes.
4. Upload file assets/appstore-logo.png vào thư mục assets/ trên repo
   (Add file → Upload files → kéo thả file → Commit). BẮT BUỘC,
   nếu thiếu logo hero sẽ bị vỡ.
5. Chờ GitHub Pages deploy (~1 phút) rồi mở lại
   https://sonsiro.github.io kiểm tra.

Lưu ý: file apps.js trong repo hiện KHÔNG được index.html dùng.
